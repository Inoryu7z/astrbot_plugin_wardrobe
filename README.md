# 👗 Wardrobe · 衣橱图鉴

给 Bot 一座属于自己的衣橱，让穿搭不止于文字描述。

**Wardrobe** 是一个图片衣柜管理插件。保存图片时由视觉模型自动分析内容并生成结构化标签，支持语义检索 + 属性匹配双重检索策略，让 Bot 在需要时精准找到合适的参考图。还支持图片转视频、自动备份、WebUI 管理界面、与 [AiImg](https://github.com/Inoryu7z/astrbot_plugin_aiimg) 双向联动。

---

## ✨ 功能概览

### 📸 智能存图

保存图片时自动调用视觉模型分析内容，生成风格、服装类型、场景、氛围、姿势、景别、表情等结构化标签，用于后续精准检索。用户提供的描述会强制写入 `description` 字段，确保意图不丢失。自动 MD5 去重，旧图启动时自动回填哈希。

### 🔍 双重检索

- **语义检索（优先）**：用 Embedding 模型把图片描述向量化，支持自然语言语义匹配，可选 Rerank 精排
- **属性匹配（回退）**：语义检索不可用时回退到属性匹配 + 模糊搜索

用户可以用自然语言检索图片，例如"有没有洛丽塔发一张看看""发一张甜美一点的衣服来"。

**按人格隔离的热度**：人格 A 用过的图对人格 B 仍显示 0 热度，内容相近时优先选低热度图。支持人格筛选、无人格筛选、优先未使用、最近调用排序、收藏/喜欢影响排序等多种模式。

### 🤖 LLM 工具

| 工具名 | 说明 |
|--------|------|
| `save_wardrobe_image` | 保存图片到衣柜库 |
| `search_wardrobe_image` | 从衣柜库中搜索图片 |

用户可以用自然语言触发，例如"这张自拍挺好看的你存一下"→ 自动存图，"有没有哥特风的图发一张"→ 自动取图。

### 🔗 与 AiImg 联动

与 [AiImg 万象绘](https://github.com/Inoryu7z/astrbot_plugin_aiimg) 是一套双子插件，两者一起安装时自动启用深度联动：

- **参考图**：AiImg 自拍时从衣橱检索参考图，返回图片路径 + 描述 + 参考强度
- **风格池**：人格级风格池供 AiImg 补拍选风格使用
- **衰减过滤**：补拍近期用过的参考图权重降低，避免重复
- **自动存图**：AiImg 自拍模式生成的图片自动存入衣橱，附带生成时所用提示词；视频也可自动入库

### 🎬 图片转视频

衣橱中的图片可转为视频：三档风格（正常/轻荤/重荤）各自绑定独立后端（复用 AiImg 的服务商注册表），Vision 模型自动生成提示词，后台异步生成。视频秒开播放，支持发送到会话、失败重试、键盘快速切换。AiImg/DailySharing 生成的视频可自动入库。

### 💾 备份与清理

- **备份**：自动定期备份，不会丢数据。WebUI 一键导出/导入，支持多文件上传自动识别全量/增量。批量模式下可按筛选条件选中导出
- **无感自动清理**：标记为"无感"的图片 30 天后自动彻底删除；自动保存的视频 7 天后清理。WebUI 手动生成的内容不受影响

### 🖥️ WebUI

完整的 Web 管理界面：图片/视频瀑布流浏览、多维筛选与排序、全屏大图键盘导航、批量操作（上传/删除/重新分析/标签/导出）、统计分析图表（景别/氛围/风格/场景分布 + 存图趋势）、标签与人格级风格池管理、图片转视频面板、备份恢复。移动端自适应。

## 🎮 可用指令

| 指令 | 权限 | 说明 |
|------|------|------|
| `/存图 [人格名] [描述]` | 管理员 | 保存图片到衣柜库（回复图片或图片+文字同时发送） |
| `/删图 <图片ID>` | 管理员 | 删除衣柜库中的图片 |
| `/衣柜统计` | 所有人 | 查看衣柜库统计信息（含图片和视频数量） |

---

## 📝 使用说明

1. 存图/取图模型需支持视觉能力，向量检索需配置 Embedding 提供商（未配置时自动回退到属性匹配）。
2. 视频功能复用 AiImg 的服务商注册表，需先安装 AiImg 并配置视频类服务商。
3. 与 AiImg 的联动功能需同时安装 AiImg 插件。
4. 详细配置项请在 AstrBot WebUI 配置面板中查看，每个字段都有说明文字。
5. 标记为"无感"的图片 30 天后会被自动删除，请慎用。
