# 👗 Wardrobe · 衣橱图鉴

给 Bot 一座属于自己的衣橱，让穿搭不止于文字描述。

**Wardrobe** 是一个图片衣柜管理插件。
它支持将图片保存到衣柜库中，通过视觉模型自动分析图片内容并生成精细的结构化标签，
支持向量语义检索和属性匹配双重检索策略，让 Bot 在需要时精准找到合适的参考图。
还支持图片转视频、自动备份、WebUI 管理界面、与 [AiImg](https://github.com/Inoryu7z/astrbot_plugin_aiimg) 双向联动等完整功能。

---

## ✨ 它能做什么

### 📸 智能存图

保存图片时，Wardrobe 会调用视觉模型自动分析图片内容，生成完整的结构化属性标签。

**基础维度**

| 字段 | 说明 |
|------|------|
| `category` | 自动判断"人物"或"衣服" |
| `style` | 从 70+ 种预定义风格中匹配（洛丽塔、JK、汉服、纯欲、暗黑等） |
| `clothing_type` | 从 70+ 种服装类型中选择 |
| `exposure_level` | 保守 / 适度 / 略暴露 / 暴露 |
| `scene` | 日常、约会、拍照、居家等 40+ 种场景 |
| `atmosphere` | 清纯、性感、可爱、优雅等 |
| `color_tone` / `composition` / `background` | 自由生成的颜色主调 / 画面构图 / 背景环境描述 |
| `description` | 详细描述图片内容，用于语义检索 |

**人物专属维度**

| 字段 | 说明 |
|------|------|
| `pose_type` | 站姿、坐姿、躺姿、自拍姿势等 |
| `body_orientation` | 身体朝向 |
| `dynamic_level` | 动态感 |
| `action_style` | 优雅端庄、性感撩人、活泼俏皮等 |
| `shot_size` | 特写、近景、中景、全景等景别 |
| `camera_angle` | 拍摄角度 |
| `expression` | 微笑、Wink、嘟嘴、吐舌等可视化表情 |

**精细化检索维度**（v2.0.0+ 新增，大幅提升搜索精准度）

| 字段 | 说明 |
|------|------|
| `exposure_features` | 非常规暴露的身体部位（乳沟、侧乳露出、露背、露肩等） |
| `key_features` | 3-5 个最突出的视觉标识——看到这个词就能想起这张图 |
| `prop_objects` | 画面中的道具/物品 |
| `allure_features` | 具有吸引力或微妙暗示感的神态、动作与姿态细节（分明确诱惑 / 姿态暗示 / 不记录三层） |
| `body_focus` | 画面刻意聚焦的身体部位（全身均衡构图不记录） |

**参考强度维度**（v2.2.3+，供 AiImg 自拍参考图调用）

| 字段 | 说明 |
|------|------|
| `ref_strength` | 姿势与构图的参考价值：`full`（轮廓剪影有独特性）/ `style`（姿势有设计意图但不足以单独模仿）/ `reimagine`（纯功能性"人形衣架"姿态）。与服装美观度完全解耦 |
| `ref_strength_reason` | 评级依据的 2-3 句自然描述（仅日志和 WebUI 可见，取图时屏蔽） |

**AI 生成图溯源**（v2.9.2+）

| 字段 | 说明 |
|------|------|
| `ai_prompt` | 由 AiImg 插件生成该图时所用的提示词。仅自拍模式自动存入衣柜时附带，手动上传/`/存图` 命令保存的图为空。WebUI 详情页为空时自动隐藏 |

用户提供的描述会被强制写入 `description` 字段，确保即使模型识别困难，用户意图也不会丢失。

存图时自动进行 MD5 去重，完全相同的图片不会重复保存。启动时自动回填旧图的 MD5 哈希值。

### 🔍 双重检索策略

Wardrobe 采用向量语义检索优先 + 属性匹配回退的双重检索策略：

**向量语义检索（优先）**
- 使用 Embedding 模型将图片描述向量化，支持自然语言语义匹配
- 向量索引纳入 `description` + `style` + `clothing_type` 等多个字段
- 支持 Rerank 重排序模型，提升检索精度
- 可配置相似度阈值和候选数量

**属性匹配检索（回退）**
- 当向量检索不可用时，回退到传统属性匹配
- 取图模型解析用户意图，生成结构化查询条件
- 数据库按属性匹配取出候选图片，取图模型从候选中选出最匹配的
- LIKE 回退增强：渐进式前缀截断 + bigram 分解 + 字符级 AND 匹配

用户可以用自然语言检索图片，例如：
- "有没有洛丽塔发一张看看"
- "发一张甜美一点的衣服来"

**按人格独立计算的热度**（v2.9.3+）

图片取用热度按人格独立计算，人格 A 用过的图对人格 B 仍显示 0 热度。取图时 LLM 能看到候选图片在当前人格下的使用次数，内容匹配度相近时优先选低热度图。空人格（未设置人格）取图不记热度。

检索支持多种模式：
- **人格模式**：按当前对话人格筛选图片
- **无人格筛选**：筛选未绑定人格的图片（v2.5.3+）
- **优先未使用**：优先选择使用次数少的图片，避免重复
- **最近调用排序**：按图片最后被调用的时间倒序排列（v2.2.8+）
- **收藏/喜欢影响排序**：开启"优先低热度"时，收藏图虚拟降低 3 点热度、喜欢图降低 1 点热度（实际 use_count 不变）

### 🤖 LLM 工具接口

Wardrobe 注册了两个 LLM 工具，对话模型可以自动调用：

| 工具名 | 说明 |
|--------|------|
| `save_wardrobe_image` | 保存图片到衣柜库 |
| `search_wardrobe_image` | 从衣柜库中搜索图片 |

这意味着用户可以用自然语言触发存图和取图，例如：
- "这张自拍挺好看的你存一下" → 自动调用 `save_wardrobe_image`
- "有没有哥特风的图发一张" → 自动调用 `search_wardrobe_image`

### 🔗 AiImg 双向联动

Wardrobe 与 [AiImg 万象绘](https://github.com/Inoryu7z/astrbot_plugin_aiimg) 是一套双子插件，单向安装任一方都能用，但两者一起安装时会自动启用深度联动。联动方向有四个：

**① 衣橱 → AiImg：自拍参考图（`get_reference_image`）**

AiImg 自拍时可调用 Wardrobe 的 `get_reference_image()` 接口获取参考图。
- 返回图片路径 + 描述 + 参考强度（`full` / `style` / `reimagine`）
- 参考强度决定参考图对生成图的指导力度
- 自动排除当前人格的图库，避免同质化
- 支持 `min_similarity` 参数收紧搜图条件
- 支持 `persona_mode` 配置：`no_persona_only`（只搜无人格图）/ `fallback_other`（优先搜无人格图再回退其他人格）

**② 衣橱 → AiImg：补拍风格池（`get_style_pool_for_persona`）**

Wardrobe 支持人格级风格池（v2.9.0+），供 AiImg 补拍 r0 算法选风格时调用：
- `get_style_pool_for_persona(persona_name)` 返回指定人格的专属风格池
- WebUI 标签分类管理中可编辑每个人格的风格列表
- 支持从全局风格池点击快速添加到人格池
- 人格池留空时自动回退到全局风格池

**③ 衣橱 → AiImg：补拍衰减过滤（`daily_selfie_use_count`）**

Wardrobe 为 AiImg 补拍提供衰减过滤机制（v2.6.5+）：
- `images` 表新增 `daily_selfie_use_count` 字段，仅统计补拍场景的选中次数
- `search()` / `get_reference_image()` 支持 `daily_selfie_mode=True`，启用指数衰减过滤（0.6^n，权重低于 0.05 直接排除）
- 每周一凌晨 4 点所有图的计数减 1（最低 0）
- 仅影响补拍场景，手动自拍和手动取图不受影响

**④ AiImg → 衣橱：自动存图**

开启 `auto_save_aiimg_enabled` 后，AiImg 生成的**自拍模式**图片会自动存入衣橱对应人格目录：
- 仅自拍模式（`/自拍` 命令及 LLM `aiimg_generate` 的 selfie 路径）自动存入，文生图/改图不存
- 自动调用衣橱视觉模型分析图片属性
- 自拍模式下生成时所用提示词会写入 `ai_prompt` 字段
- 自动存视频：`auto_save_video_enabled`（继承 `auto_save_aiimg_enabled`），AiImg/DailySharing 生成的视频自动存入视频库

### 🎬 图片转视频

支持将衣橱中的图片转为视频：

- 三档视频风格：正常、轻荤、重荤，每档可独立绑定不同的视频后端（复用 AiImg Provider Registry）
- 视频提示词自动生成：调用 Vision 模型根据图片内容和档位生成动态提示词
- 支持直连 API 方式调用 Vision 模型（`video_prompt_base_url` + `video_prompt_api_key`），绕过 Provider 传图不可靠问题
- 系统提示词可自定义，持久化到配置文件
- 视频后台异步生成，不阻塞前端操作
- 视频流式播放 + MP4 faststart 后处理：moov atom 前移，秒开播放，支持 Range 分段请求与 ETag 缓存
- 失败视频支持重试和删除，重试复用已有提示词不重复调用 LLM
- 视频播放器支持左右箭头快速切换和键盘导航（← → 切换，Esc 关闭）
- **视频发送到会话**（v2.6.0+）：WebUI 视频设置中配置 UMO 值后，可将视频发送到指定会话；生成后可自动发送，也可手动点击"发送视频"按钮
- 自动存视频：AiImg/DailySharing 生成的视频可自动存入视频库，MD5 去重

### 💾 备份与恢复

Wardrobe 采用**每月全量 + 每日增量**的备份策略（v2.7.0+ 重构），解决大量图片时服务器压力过大问题：

- **全量备份**：每月一次，凌晨 4 点执行，使用重度节流（每文件 sleep 0.5s），文件名 `full_YYYY-MM-DD.zip`
- **增量备份**：每日一次，凌晨执行，只包含新增记录，使用轻度节流（0.1s），文件名 `incr_YYYY-MM-DD.zip`
- 图片/视频文件使用 ZIP_STORED（不压缩），避免对已压缩格式做无效 CPU 消耗
- 自动清理：保留 30 天内备份，始终保留最新全量备份
- 备份文件位于 `plugin_data/astrbot_plugin_wardrobe/backups/`
- 备份格式 v3.0，metadata 含 `type` 字段区分全量/增量
- **WebUI 一键导出备份**：所有图片元数据、图片文件、关联视频、视频设置打包为 zip 下载
- **WebUI 一键恢复备份**：支持**多文件上传**，系统自动识别全量/增量并按时间顺序恢复，已有数据按 ID 跳过不覆盖
- **选中导出**（v2.8.1+）：批量模式下可将选中图片导出为纯图片 ZIP 或完整备份 ZIP（可导入其他服务器）
- 备份包含 `image_usage` 按人格热度记录与 `ai_prompt` 字段
- 可通过 `auto_backup_enabled` 关闭自动备份以节省存储空间（默认开启）

### 🧹 自动清理策略

为控制存储空间，Wardrobe 提供两种自动清理机制（v2.8.0+）：

**无感模式自动删除**
- 标记为"无感"（favorite=meh）的图片超过 30 天后自动彻底删除（文件 + 数据库 + 向量索引 + 关联视频）
- 每天凌晨 5:30 清理
- 无感与"无标签"的区别：只有无感标签的图片才会被自动删除，无标签图片不会被自动清理

**视频保留策略**
- 自动保存的视频（DailySharing 等插件产生的）超过 7 天后自动删除文件和记录
- 每天凌晨 5 点清理
- WebUI 手动生成的视频不受保留策略影响

### 🖥️ WebUI 管理界面

提供完整的 Web 管理界面：

- **图片库**：瀑布流（按原始宽高比展示，移动端自适应）/ 大图双视图、分类/人格/风格/场景/氛围/景别/收藏/无感/参考强度多维筛选、最新上传/喜爱优先/热度优先/最近调用/随机多种排序
- **视频库**：按档位/人格/状态/源图片筛选，视频播放器支持快速切换、键盘导航、流式播放
- **图片详情**：查看/编辑所有属性标签（含 `ai_prompt`）、收藏/喜欢/无感标记、参考强度面板式三档选择、重新分析
- **全屏大图**：lightbox 支持 ← → 切换上一张/下一张，键盘导航，显示图片序号计数器，当前图优先加载
- **批量操作**：批量上传、批量删除、批量重新分析、批量标签（收藏/喜欢/无感/取消）、批量全选（按筛选条件）、批量清除热度、批量导出图片/备份
- **统计分析**：景别/氛围/风格/场景分布图表（饼图/环形图/Treemap 钻入）、存图趋势折线图，点击图表区域可跳转图片视图并应用对应筛选
- **标签管理**：自定义标签分类和选项、人格级风格池管理
- **视频生成**：图片转视频面板，生成后自动发送选项
- **备份恢复**：导出/导入备份，多文件上传自动识别全量/增量

**性能优化**：缩略图预生成、HTTP 缓存头（7天 + ETag）、IntersectionObserver 原图懒加载、content-visibility 跳过离屏渲染、DocumentFragment 批量插入、轻量列表 API 按需加载详情。

## ⚙️ 主要配置项

### 存图模型

| 配置项 | 说明 |
|--------|------|
| `save_provider_id` | 存图主模型（需支持视觉能力） |
| `save_secondary_provider_id` | 存图备用模型（主模型超时/失败时自动切换） |
| `save_timeout_seconds` | 存图模型超时秒数（默认 60） |

### 取图模型

| 配置项 | 说明 |
|--------|------|
| `search_provider_id` | 取图主模型（需支持视觉能力） |
| `search_secondary_provider_id` | 取图备用模型 |
| `search_timeout_seconds` | 取图模型超时秒数（默认 30） |

### 向量检索

| 配置项 | 说明 |
|--------|------|
| `embedding_provider_id` | Embedding 模型提供商 |
| `rerank_provider_id` | Rerank 重排序模型提供商（可选） |
| `rerank_top_k` | Rerank 返回的最大结果数 |
| `rerank_min_candidates` | Rerank 最小候选数 |
| `vector_search_min_similarity` | 向量检索最小相似度阈值（默认 0.5） |

### 搜索行为

| 配置项 | 说明 |
|--------|------|
| `search_candidate_limit` | 从数据库取出的候选图片数量（默认 20） |
| `search_max_select` | 取图模型最多选择的图片数量（默认 1） |
| `search_prioritize_unused` | 优先选择使用次数少的图片（默认开启） |
| `search_include_user_tags` | 搜索时是否包含用户自定义标签 |
| `search_persona_mode` | 参考图人格搜索策略（仅影响 AiImg 参考图搜索）：`no_persona_only` 只搜无人格图 / `fallback_other` 优先搜无人格图再回退其他人格 |

### 存图行为

| 配置项 | 说明 |
|--------|------|
| `save_feedback_enabled` | 存图后是否向用户发送描述和属性信息（默认关闭） |
| `max_image_size_mb` | 图片大小限制 MB（默认 10） |

### 人格配置

| 配置项 | 说明 |
|--------|------|
| `personas` | 人格配置列表，每个人格包含规范名和别名列表 |

在「人格配置列表」中添加人格，每个人格包含：
- **人格名称（规范名）**：存入数据库时使用的标准名称
- **别名列表**：LLM 可能使用的其他称呼

配置后，存图/取图时会根据当前对话人格自动筛选图片。每个人格还可独立配置专属风格池（在 WebUI 标签分类管理中编辑）。

### 自动存图与视频

| 配置项 | 说明 |
|--------|------|
| `auto_save_aiimg_enabled` | AiImg 生图自动存图开关（默认关闭，仅保存自拍模式） |
| `auto_save_video_enabled` | 自动存视频开关（继承 `auto_save_aiimg_enabled`） |

### 备份

| 配置项 | 说明 |
|--------|------|
| `auto_backup_enabled` | 自动备份开关（默认开启，可关闭以节省存储空间） |

### WebUI

| 配置项 | 说明 |
|--------|------|
| `webui_enabled` | 启用 WebUI 管理界面（默认关闭） |
| `webui_host` | WebUI 监听地址 |
| `webui_port` | WebUI 端口 |
| `webui_password` | WebUI 登录密码 |

### 视频功能

| 配置项 | 说明 |
|--------|------|
| `video_enabled` | 启用图片转视频功能（默认关闭） |
| `video_prompt_provider_id` | 视频提示词生成模型提供商 |
| `video_prompt_base_url` | 直连 API 地址（可选，优先于 Provider） |
| `video_prompt_api_key` | 直连 API Key |
| `video_prompt_model` | 直连 API 模型名 |
| `video_normal_default_backend` | 正常档默认视频后端 |

视频后端通过 AiImg 插件的 ProviderRegistry 调用，需确保 AiImg 已激活并配置了视频后端。

## 📝 使用说明

1. 存图和取图模型均需支持视觉能力，请在配置中选择合适的模型提供商。
2. 存图时如果模型分析失败，图片仍会保存，但标签和描述为空。
3. 开启 `save_feedback_enabled` 后，存图时会返回图片的完整属性分析结果。
4. 检索图片时，结果会直接发送，无需用户额外确认。
5. 向量检索需要配置 Embedding 模型提供商，未配置时自动回退到属性匹配。
6. 视频功能需要单独启用，且需要配置视频后端和提示词生成模型。视频后端复用 AiImg 的 ProviderRegistry，需先安装 AiImg 并配置视频类服务商。
7. 与 AiImg 联动功能（参考图、风格池、衰减过滤、自动存图）需同时安装 AiImg 插件。
8. 标记为"无感"的图片 30 天后会被自动删除，请慎用该标记。
