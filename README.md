# 👗 Wardrobe · 衣橱图鉴

给 Bot 一座属于自己的衣橱，让穿搭不止于文字描述。

**Wardrobe** 是一个图片衣柜管理插件。
它支持将图片保存到衣柜库中，通过视觉模型自动分析图片内容并生成精细的结构化标签，
支持向量语义检索和属性匹配双重检索策略，让 Bot 在需要时精准找到合适的参考图。
还支持图片转视频、自动备份、WebUI 管理界面等完整功能。

---

## ✨ 它能做什么

### 📸 智能存图

保存图片时，Wardrobe 会调用视觉模型自动分析图片内容，生成完整的结构化属性标签。

分析维度包括：
- **分类**：自动判断"人物"或"衣服"
- **风格**：从 70+ 种预定义风格中匹配（洛丽塔、JK、汉服、纯欲、暗黑等）
- **服装类型**：从 70+ 种服装类型中选择
- **暴露程度**：保守 / 适度 / 略暴露 / 暴露
- **适用场景**：日常、约会、拍照、居家等 40+ 种场景
- **氛围**：清纯、性感、可爱、优雅等
- **姿势与动作**（人物专属）：站姿、坐姿、躺姿、自拍姿势等
- **构图与景别**（人物专属）：特写、近景、中景、全景等
- **表情**（人物专属）：微笑、Wink、嘟嘴、吐舌等可视化表情
- **动作风格**（人物专属）：优雅端庄、性感撩人、活泼俏皮等
- **颜色主调 / 画面构图 / 背景环境**：自由生成描述

用户提供的描述会被强制写入 `description` 字段，确保即使模型识别困难，用户意图也不会丢失。

存图时自动进行 MD5 去重，完全相同的图片不会重复保存。启动时自动回填旧图的 MD5 哈希值。

### 🔍 双重检索策略

Wardrobe 采用向量语义检索优先 + 属性匹配回退的双重检索策略：

**向量语义检索（优先）**
- 使用 Embedding 模型将图片描述向量化，支持自然语言语义匹配
- 支持 Rerank 重排序模型，提升检索精度
- 可配置相似度阈值和候选数量

**属性匹配检索（回退）**
- 当向量检索不可用时，回退到传统属性匹配
- 取图模型解析用户意图，生成结构化查询条件
- 数据库按属性匹配取出候选图片，取图模型从候选中选出最匹配的

用户可以用自然语言检索图片，例如：
- "有没有洛丽塔发一张看看"
- "发一张甜美一点的衣服来"

检索支持多种模式：
- **人格模式**：按当前对话人格筛选图片
- **无人格筛选**：筛选未绑定人格的图片
- **优先未使用**：优先选择使用次数少的图片，避免重复

### 🤖 LLM 工具接口

Wardrobe 注册了两个 LLM 工具，对话模型可以自动调用：

| 工具名 | 说明 |
|--------|------|
| `save_wardrobe_image` | 保存图片到衣柜库 |
| `search_wardrobe_image` | 从衣柜库中搜索图片 |

这意味着用户可以用自然语言触发存图和取图，例如：
- "这张自拍挺好看的你存一下" → 自动调用 `save_wardrobe_image`
- "有没有哥特风的图发一张" → 自动调用 `search_wardrobe_image`

### 🔗 AiImg 双向联动

Wardrobe 支持与 AiImg 插件双向联动：

**方向一：AiImg → 衣橱（自动存图）**
- AiImg 生成图片后，Wardrobe 可自动捕获并保存到衣柜库
- 自动调用视觉模型分析图片属性，归入对应人格目录
- 配置项：`auto_save_aiimg_enabled`（默认关闭）

**方向二：衣橱 → AiImg（参考图）**
- AiImg 生图时可调用 Wardrobe 的 `get_reference_image` 接口获取参考图
- 支持三种参考强度：完整参考、风格参考、重构
- 可配置相似度阈值
- 自动排除当前人格的图库，避免同质化

### 🎬 图片转视频

支持将衣橱中的图片转为视频：

- 三档视频风格：正常、轻荤、重荤，每档可独立绑定不同的视频后端
- 视频提示词自动生成：调用 Vision 模型根据图片内容和档位生成动态提示词
- 支持直连 API 方式调用 Vision 模型，绕过 Provider 传图不可靠问题
- 系统提示词可自定义，持久化到配置文件
- 视频后台异步生成，不阻塞前端操作
- 失败视频支持重试和删除
- 视频播放器支持快速切换和键盘导航
- 自动存视频：AiImg/DailySharing 生成的视频可自动存入视频库

### 💾 备份与恢复

- WebUI 一键导出备份：所有图片元数据和图片文件打包为 zip 下载
- WebUI 一键恢复备份：上传 zip 备份文件恢复，已有数据按 ID 跳过不覆盖
- 每日凌晨 1 点自动备份，保留最近 1 份
- 备份文件位于 `plugin_data/astrbot_plugin_wardrobe/backups/`

### 🖥️ WebUI 管理界面

提供完整的 Web 管理界面：

- **图片库**：瀑布流/大图双视图、分类/人格/风格/场景/氛围/景别/收藏多维筛选、排序
- **视频库**：按档位/人格/状态筛选，视频播放器支持快速切换
- **图片详情**：查看/编辑所有属性标签、收藏/喜欢、参考强度设置、重新分析
- **批量操作**：批量上传、批量删除、批量重新分析
- **统计分析**：景别/氛围/风格/场景分布图表、存图趋势
- **标签管理**：自定义标签分类和选项
- **备份恢复**：导出/导入备份

## 🎮 可用指令

| 指令 | 权限 | 说明 |
|------|------|------|
| `/存图` | 管理员 | 保存图片到衣柜库（回复图片消息或图片+文字同时发送） |
| `/删图 <图片ID>` | 管理员 | 删除衣柜库中的图片 |
| `/衣柜统计` | 所有人 | 查看衣柜库统计信息（含图片和视频数量） |

## ⚙️ 主要配置项

### 存图模型

| 配置项 | 说明 |
|--------|------|
| `save_provider_id` | 存图主模型（需支持视觉能力） |
| `save_secondary_provider_id` | 存图备用模型（主模型超时/失败时自动切换） |
| `save_timeout_seconds` | 存图模型超时秒数（默认 60） |

### 取图模型

| 配置项 | 说明 |
|--------|------|
| `search_provider_id` | 取图主模型（需支持视觉能力） |
| `search_secondary_provider_id` | 取图备用模型 |
| `search_timeout_seconds` | 取图模型超时秒数（默认 30） |

### 向量检索

| 配置项 | 说明 |
|--------|------|
| `embedding_provider_id` | Embedding 模型提供商 |
| `rerank_provider_id` | Rerank 重排序模型提供商（可选） |
| `rerank_top_k` | Rerank 返回的最大结果数 |
| `rerank_min_candidates` | Rerank 最小候选数 |
| `vector_search_min_similarity` | 向量检索最小相似度阈值 |

### 搜索行为

| 配置项 | 说明 |
|--------|------|
| `search_candidate_limit` | 从数据库取出的候选图片数量（默认 20） |
| `search_max_select` | 取图模型最多选择的图片数量（默认 1） |
| `search_prioritize_unused` | 优先选择使用次数少的图片（默认开启） |
| `search_include_user_tags` | 搜索时是否包含用户自定义标签 |
| `search_persona_mode` | 人格筛选模式 |

### 存图行为

| 配置项 | 说明 |
|--------|------|
| `save_feedback_enabled` | 存图后是否向用户发送描述和属性信息（默认关闭） |
| `max_image_size_mb` | 图片大小限制 MB（默认 10） |

### 人格配置

| 配置项 | 说明 |
|--------|------|
| `personas` | 人格配置列表，每个人格包含规范名和别名列表 |

在「人格配置列表」中添加人格，每个人格包含：
- **人格名称（规范名）**：存入数据库时使用的标准名称
- **别名列表**：LLM 可能使用的其他称呼

配置后，存图/取图时会根据当前对话人格自动筛选图片。

### 自动存图

| 配置项 | 说明 |
|--------|------|
| `auto_save_aiimg_enabled` | AiImg 生图自动存图开关（默认关闭） |
| `auto_save_video_enabled` | 自动存视频开关（继承 auto_save_aiimg_enabled） |

### WebUI

| 配置项 | 说明 |
|--------|------|
| `webui_enabled` | 启用 WebUI 管理界面（默认关闭） |
| `webui_host` | WebUI 监听地址 |
| `webui_port` | WebUI 端口 |
| `webui_password` | WebUI 登录密码 |

### 视频功能

| 配置项 | 说明 |
|--------|------|
| `video_enabled` | 启用图片转视频功能（默认关闭） |
| `video_prompt_provider_id` | 视频提示词生成模型提供商 |
| `video_prompt_base_url` | 直连 API 地址（可选，优先于 Provider） |
| `video_prompt_api_key` | 直连 API Key |
| `video_prompt_model` | 直连 API 模型名 |
| `video_normal_default_backend` | 正常档默认视频后端 |
| `video_light_spicy_default_backend` | 轻荤档默认视频后端 |
| `video_heavy_spicy_default_backend` | 重荤档默认视频后端 |

## 📝 使用说明

1. 存图和取图模型均需支持视觉能力，请在配置中选择合适的模型提供商。
2. 存图时如果模型分析失败，图片仍会保存，但标签和描述为空。
3. 开启 `save_feedback_enabled` 后，存图时会返回图片的完整属性分析结果。
4. 检索图片时，结果会直接发送，无需用户额外确认。
5. 向量检索需要配置 Embedding 模型提供商，未配置时自动回退到属性匹配。
6. 视频功能需要单独启用，且需要配置视频后端和提示词生成模型。
